# Instrucciones para agentes de IA

Estas instrucciones se aplican a toda la repo. El [README](README.md) funciona como índice del trabajo y el [enunciado](docs/enunciado/P1.docx.pdf) es la fuente de los requisitos académicos.

## Al trabajar en la repo

- Lee el README y los documentos pertinentes antes de editar. Comprueba el estado de Git y conserva los cambios existentes.
- Trabaja en los archivos correspondientes al ejercicio solicitado; mantén la organización y los nombres actuales salvo que la tarea requiera cambiarlos.
- Escribe la documentación en español. Distingue lo que indica el enunciado, las decisiones comunicadas por el equipo y las cuestiones aún pendientes.
- No inventes decisiones, aprobaciones, datos de ejecución ni resultados. Conserva las versiones y las evidencias originales de evaluaciones de IA.
- Actualiza el índice del README cuando cambie el progreso confirmado o se añadan entregables.
- Mantén los cambios centrados en la petición. Git conserva el historial; no hace falta crear registros de cambios para cada edición documental.
- Antes de terminar, revisa el diff y ejecuta `git diff --check`. Si cambias código, ejecuta las pruebas pertinentes disponibles.

Resume los archivos modificados, las comprobaciones ejecutadas y las decisiones que todavía requieran atención del equipo. No marques un ejercicio como terminado sin confirmación del equipo.
